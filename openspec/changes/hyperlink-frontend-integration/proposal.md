# OpenSpec Proposal: 超链接前端集成

## Why

当前项目中，用户无法查看技能描述、武器特效等文本中的超链接详细内容，这影响了用户体验和对游戏机制的理解。后端已经包含了完整的超链接数据，但前端缺乏相应的展示机制，导致这些有价值的信息无法有效传递给用户。

## What Changes

本提案将实现以下核心变更：

1. **后端数据处理修正**: 修改 `genshindata/utility.go` 中的正则表达式，将超链接标记 `{LINK#id}text{/LINK}` 转换为HTML `<span class="hyperlink" xlink:href="id">text</span>` 而不是替换为空白

2. **前端超链接处理系统**: 创建完整的超链接处理和显示系统，包括：
   - `HyperlinkService`: 处理超链接标记解析、内容获取和多语言支持
   - `HyperlinkInteractionDirective`: 为超链接元素添加鼠标交互功能
   - 智能定位的tooltip系统，根据屏幕位置自动调整显示方向
   - 支持语言切换时的实时内容更新

3. **多语言内容预加载**: 实现所有语言版本的预加载机制，确保语言切换时tooltip内容能够立即更新，无需重新请求数据

4. **数据服务集成**: 扩展现有的数据服务，支持超链接、教学提示和术语数据的加载和访问

## 背景

当前项目中，后端生成的JSON数据已经包含了超链接(HYPERLINK)、教学提示(PushTips)和术语(ManualTextMap)的数据，但在前端显示时存在以下问题：

1. 在 `genshindata/utility.go` 中，`regexLayout3` 和 `regexLayout4` 将所有文本的超链接Tip内容都替换为空白文字
2. 前端没有处理超链接标记的机制，导致超链接内容无法正确显示
3. 数据结构中的 `GenshinPushTipsListData`、`GenshinTutorialDetailData`、`GenshinHyperLinkNameData`、`GenshinManualTextMapData` 存在结构问题

## 目标

1. 修正后端数据处理，保留超链接标记而不是替换为空白
2. 确保超链接、教学提示和术语数据正确生成
3. 在前端创建超链接处理服务，用于解析和显示超链接内容
4. 创建超链接显示组件，支持鼠标悬停显示详细内容
5. 修改前端显示组件，使用innerHTML替代innerText以支持HTML超链接
6. 确保超链接功能在不同语言下正常工作

## 解决方案

### 后端修改

1. **修改 `genshindata/utility.go` 中的正则表达式处理**
   - 修改 `regexLayout3Replaced` 和 `regexLayout4Replaced`，保留超链接标记而不是替换为空白
   - 可能需要添加新的正则表达式来处理超链接标记

2. **修正数据结构**
   - 修正 `GenshinPushTipsListData`、`GenshinTutorialDetailData`、`GenshinHyperLinkNameData`、`GenshinManualTextMapData` 的数据结构
   - 确保这些数据结构能够正确映射到前端需要的格式

3. **确保数据正确生成**
   - 确保从 `@/tmp/` 目录读取的JSON文件能够正确处理
   - 确保TextMapHash能够正确映射到各种语言的实际文本

### 前端实现

1. **创建超链接处理服务**
   - 创建一个新的服务来处理超链接标记的解析
   - 该服务将解析 `{LINK#id}...{/LINK}` 标记，并从超链接数据中获取相应内容
   - 支持多语言环境下的超链接内容显示

2. **创建超链接显示组件**
   - 创建一个新的Angular组件来显示超链接
   - 该组件将显示特殊样式的文本，并在鼠标悬停时显示详细内容的工具提示
   - 支持自定义样式和位置

3. **修改现有显示组件**
   - 修改显示技能描述、武器特效等文本的组件
   - 使用 `innerHTML` 替代 `innerText` 以支持HTML超链接
   - 集成超链接处理服务和组件

## 实施计划

1. **后端修改**
   - 修改 `genshindata/utility.go` 中的正则表达式处理
   - 修正数据结构定义
   - 确保数据正确生成和映射

2. **前端服务开发**
   - 创建超链接处理服务
   - 实现超链接标记解析逻辑
   - 集成到现有数据服务中

3. **前端组件开发**
   - 创建超链接显示组件
   - 实现工具提示功能
   - 添加样式和动画效果

4. **集成和测试**
   - 修改现有显示组件以使用新的超链接功能
   - 测试不同语言环境下的显示效果
   - 性能优化和错误处理

## 预期效果

实施完成后，用户将能够：

1. 在技能描述、武器特效等文本中看到特殊样式的超链接文本
2. 将鼠标悬停在超链接上时，看到相关的详细内容
3. 在不同语言环境下都能正确显示超链接内容

## 风险和挑战

1. **性能影响**：处理大量超链接可能会影响页面渲染性能
2. **兼容性**：需要确保在不同浏览器和设备上都能正常工作
3. **数据一致性**：需要确保超链接数据与实际内容保持同步

## 成功指标

1. 超链接能够正确显示并响应鼠标悬停事件
2. 工具提示能够正确显示超链接的详细内容
3. 在所有支持的语言环境下都能正常工作
4. 不影响现有功能的性能和稳定性
